# Marel v2

Marel'in plise perde, jaluzi, zip perde, sineklik ve sürgülü kapı ürünleri için hazırlanan parallax satış vitrini.

## Sayfalar

- `/` — ana sayfa, ürün grupları, koleksiyonlar, duyurular ve galeri
- `/urunler` — ürün grupları vitrini
- `/urunler/plise-perde/diamond-serisi` — Diamond seri tanıtımı ve WhatsApp teklif oluşturucu

## Yerel çalışma

```bash
npm install
npm run dev
npm run build
```

Teklif formu kumaş rengi, kasa rengi, genişlik, yükseklik ve adet seçimlerini yapılandırılmış WhatsApp mesajına dönüştürür.
